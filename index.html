功能模块与 User Story
01
Module 1 · HomePage
用户打开 App 后的首屏，聚焦「一眼看清资产，一步发起操作」
INT-001
US-1
阿珍：我能一目了然资产总价值及最近的涨跌情况
P0总资产估值（USD） P0今日涨跌幅 + 折线缩略图 P0Donut 图（Token/DeFi 占比）
US-2
阿珍：我能在 Homepage 快速发起常用操作
P0Send 按钮 P0Receive 按钮 P0Stake 按钮 → 质押页 P0Agent 按钮 → AI Agent 页
US-3
阿珍：我能看到账户最近的交易记录，区分链上与链下活动
P0Homepage Recent Activity 预览（5 条） P0完整 Activity 列表（On-Chain / Off-Chain） P1筛选栏（Type / Status / Time） P1交易详情页（Hero · Token Flow · Fields）
US-4
阿珍：我能根据需要自定义首页显示的内容，例如行情等
P2首页 Widget 自定义（规划中） P2行情 / 市场数据模块（规划中）
02
Module 2 · Portfolio Dashboard
以「现金 / 存款与收益 / 负债」三类资产维度呈现持仓结构
INT-001 · INT-002
US-1
阿珍：我能清楚看到资产的种类，包括随时可以消费的现金、固定的存款和收益、欠款及需要支付的利息
P0Token Tab → 现金（自由流通代币） P0DeFi Tab → 存款 / 质押 / LP 仓位 P0DeFi Tab → 借贷仓位（Aave V3） P0凭证代币标注「In DeFi」，不重复计价
US-2
阿珍：我看到的现金价值是能够实时变成法币的价值
P0Token Tab 跨链聚合余额 × 实时报价 P0Token 持仓小计（凭证代币已排除） P1报价实时刷新（60s 缓存，下期接入）
US-3
阿珍：我看到的存款价值应该包含存入的仓位及产生的收益，同时能够根据存款类型显示额外的信息，例如质押展示年化及提取时间、添加流动性展示代币实时余额及价值等
P0质押类 → 总量 · 收益 · APY · 提取入口 P0借贷类 → 供应量 + 供应 APY P0LP 类 → Token 余额 + 价格区间 P0多产品协议 → 按产品子类分组展示
US-4
阿珍：我看到的负债价值应该包含我借出的资金价值及已经产生的利息，同时能够显示当前借款仓位的健康程度
P0借贷仓位卡片 → 借款容量 · Health Factor 进度条 P1负债利息实时累计 + 清算风险预警（下期接入）
03
Module 3 · Token Profile
以代币为中心的纵深视图：聚合余额 → 链分布 → 价格 → 操作
INT-002 · INT-003
US-1
阿珍：我能看到某个代币在多链账户下的余额，统一管理资产
P0Token Tab 同代币跨链聚合显示总价值 P0Token Detail → 聚合总余额 + 法币价值
US-2
阿珍：我能在代币详情页看到当前代币在特定公链网络及地址下的余额，精准管理资金
P0「按网络分布」可折叠区块（各链余额） P1多地址网络行 inline 展开（账户昵称 + 地址）
US-3
阿珍：我能在代币详情页看到代币的价格走势图
P0价格走势图（24h / 7d / 30d / 1y 切换） P0价格变动文案（口径与所选周期一致）
US-4
阿珍：我能在代币详情页看到代币信息以帮我更了解当前代币
P0About 区块（代币简介） P0市场统计（市值 · 24h 量 · 流通量 · ATH）
US-5
阿珍：我能在代币详情页看到代币交易记录，了解当前代币最近的活动
P0近期交易列表（类型 · 时间 · 金额） P0点击进入交易详情页
US-6
阿珍：我能在代币详情页看到代币授权情况
P2Token Approvals 视图（规划中，未在原型实现）
US-7
阿珍：我能在代币详情页看到代币支持的功能并快速操作
P1Send → 三层级发送流程 P1Receive → 三层级收款 + QR P2Swap 兑换界面（下期实现） P1Dust 代币提示 + 处理引导
